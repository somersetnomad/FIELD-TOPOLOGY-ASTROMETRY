## 8. Installation & Deployment

### Quick Local Run
Because the application is packaged as a self-contained single-file web system, no build steps or package managers are required:

```bash
git clone https://github.com/your-username/field-topology-astrometry.git
cd field-topology-astrometry
# Open in your default browser
open index.html
```

### GitHub Pages Deployment
1. Push `index.html` and `README.md` to your repository.
2. In your GitHub repository, open **Settings > Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/(root)`.
4. Click **Save**. The observatory will be live at `https://your-username.github.io/field-topology-astrometry/`.
